## Introduction

<div align=center style="color:white;background-color:hsl(211, 44%, 20%);font-size:2rem;font-weight:1;padding:1rem">

This final project concludes this module on React!</div>

During this project, you will be assessed on how well you have achieved the learning goals of this module and are now able to:

- **Debug** in React more efficiently.

- Build an **advanced** React app.

- Connect your app to a **back-end server**.

- Use a **state management library to manage state** more efficiently.

- Use a form library to create a **form** to upload and edit data.

- Work with complex UI elements like **modals and skeletons**.

- Work with (custom) React **Hooks**.

- Work with React **Router** to navigate through different page components.

During this project, you will develop a complex React application that communicates with a back-end server. You will need to apply all the concepts and skills you have learned and mastered in this module:

- Profiling and `<ErrorBoundaries />`.

- Component composition.

- Context.

- Hooks.

- State management.

- Talking to an API.

- Routing.

- Forms, Skeletons and Modals.

### Evaluation

This project will be evaluated by our mentors, who will give you feedback on what you did well, what you need to improve **(must haves)**, and/or what would be nice to improve **(nice to haves)** and on how you can make these improvements.<br>
You can continue to make improvements and hand in the project for evaluation and feedback as often as necessary.<br>
You need a pass for this project to receive your certification at the end of the course. Many students fail the first time and submit the project several times, so don't worry if this also happens to you.
